# Energy IQ - Electricity Consumption Dashboard

A high-fidelity, hackathon-ready energy management dashboard designed for tracking, analyzing, and optimizing electricity consumption. Built with a focus on real-time data visualization and efficient resource management.

## 🚀 Features

- **Real-Time Dashboard**: Live data visualization of energy consumption metrics.
- **Admin Panel**: Dedicated administration interface for managing users, settings, and thresholds.
- **Automated Alerts**: Mechanisms to trigger emergency alerts based on customizable energy thresholds (e.g., phantom drain alerts).
- **Billing Estimation**: System to estimate electricity bills based on live consumption data.
- **Firebase Integration**: Real-time database and authentication via Firebase.
- **Responsive Design**: Professional and modern UI optimized for various devices.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS, JavaScript
- **Backend & Database**: Firebase (Authentication & Realtime Database)
- **Local Server**: PowerShell (`server.ps1`) for local testing

## 📂 Project Structure

- `/css` - Stylesheets for dashboard, admin, and login components.
- `/js` - Logic for dashboard interactions, admin controls, Firebase configuration, and authentication.
- `index.html` - Landing/Login page.
- `dashboard.html` - Main user dashboard for monitoring energy.
- `admin.html` - Administrative control panel.

## ⚙️ How to Run Locally

1. Clone the repository.
2. Start the local server by running the `server.ps1` PowerShell script, or use any standard live server extension (like VS Code's Live Server).
3. Navigate to `index.html` in your browser.
